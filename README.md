# Интерактивное приглашение на свидание

Небольшой адаптивный сайт без сборки и без сервера. Откройте `index.html` в браузере для локального просмотра.

## Что внутри
- Конверт и первый экран.
- Стираемый защитный слой, который работает мышью и пальцем.
- Кнопка «Нет», которая активно убегает при наведении курсора и при попытке нажатия/касания.
- Выбор одного варианта свидания.
- Полный календарь с переключением месяцев и лет; прошедшие даты недоступны.
- Выбор времени с шагом 30 минут с 09:00 до 22:00 и итоговая карточка.
- Кнопка, открывающая Telegram с подготовленным сообщением, которое можно отправить в выбранный чат.

## Публикация на GitHub Pages
1. Войдите в GitHub и создайте новый публичный репозиторий, например `date-invitation`.
2. Загрузите в корень репозитория три файла: `index.html`, `styles.css`, `script.js`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. В качестве ветки выберите `main`, папку `/ (root)`, затем нажмите **Save**.
6. Подождите минуту или две. В разделе Pages появится адрес вида `https://ВАШ-ЛОГИН.github.io/date-invitation/`.
7. Откройте ссылку на телефоне и проверьте все шаги. После этого отправьте ссылку ей в Telegram.

## Важные детали
- Кнопка Telegram открывает окно пересылки с готовым текстом. Она не отправляет сообщение автоматически: нужно выбрать чат и нажать «Отправить».
- Дата и время не бронируются автоматически — это выбор предпочтений, который она отправляет вам сообщением.
- Внешний шрифт загружается из Google Fonts; если он недоступен, сайт использует системный шрифт.
